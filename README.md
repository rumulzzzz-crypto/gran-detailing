# Грань — уход в деталях

Авторский концепт сайта детейлинг-студии. Дизайн и разработка — Микаил Дадашов. Страница демонстрирует дизайн и взаимодействия, а не услуги действующей студии. Автомобильные изображения созданы ИИ.

## Возможности

- Тёмный первый экран, адаптивная композиция и мобильная навигация.
- Подбор ухода по задаче, вкладки услуг с плавной сменой фотографий.
- Сравнение до/после, этапы работы и раскрывающиеся вопросы.
- Объяснение возможностей услуг и факторов стоимости.
- Демонстрационная форма подготовки и копирования обращения с пожеланиями. Нет сетевой отправки, регистрации и хранения данных.
- Клавиатурная навигация, видимый фокус и поддержка уменьшенной анимации.

## Локальный запуск

Нужен Node.js: `node server.mjs`, затем http://127.0.0.1:4178. Зависимости и сборка не требуются.

## Публикация

Статические HTML, CSS, JavaScript и WebP. Настройки Vercel находятся в vercel.json. Локальный сервер, служебные файлы и исходный PNG исключены из выкладки через .vercelignore.

Шрифты Manrope включены вместе с лицензией в assets/fonts/manrope-LICENSE.txt. Georgia используется из системных шрифтов.
